# 坦克大战 Tank Battle

单文件 HTML5 Canvas 版经典《坦克大战》,无需构建、无依赖,双击 `index.html` 即可游玩。

## 玩法

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键 / WASD |
| 射击 | 空格 / J |
| 暂停 | P |
| 开始 / 重来 | 回车 |

- 消灭所有敌方坦克过关,保护底部的基地(金色老鹰)。
- 砖墙可被击毁,钢墙不可摧毁,水面坦克不可通过,草丛遮挡视线。
- 每关随机生成对称地图,敌人数量、种类随关卡递增(灰色普通 / 红色快速 / 绿色装甲三次命中)。
- 最高分保存在浏览器 localStorage 中。

## 运行

直接用浏览器打开 `index.html`,或:

```bash
python -m http.server 8000
```
